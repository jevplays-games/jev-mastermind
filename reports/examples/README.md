# Example exports

Generated by scripted local-server play through the offline DOM harness. These are actual outputs of the application, not simulated live-provider claims or human-subject data.

The sample has 5 human-side guesses and 2 local-opponent guesses. Its full-alternative CSV contains 9,072 rows: one for each of 1,296 legal guesses at every played turn.

- `sample-analytics.json`: complete selected-move and counterfactual report.
- `sample-moves.csv`: one row per actual guess.
- `sample-decisions.csv`: actual accepted local decisions, explicitly labeled `local`.
- `sample-all-alternatives.csv`: every legal alternative and feedback partition.
- `sample-replay.json`: internally valid replay including terminal code/salt reveal.
- `tampered-replay.fixture.json`: deliberate negative test; the salt was changed and verification must fail.

All codes and salts are disposable test-game values. No authentication sessions, private API keys or real Discord identities are included.
